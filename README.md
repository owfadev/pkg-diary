# pkg-diary

vault-wiki optional package **diary** — personal diary zone backed by the vault domain: `vault/diary/`, one md file per day (`YYYY-MM-DD.md`), agent appends the user's words verbatim, edit/delete freedom belongs to the human. No network, no credentials, no wiki projection by default. See [PKG.yaml](PKG.yaml) for members/compat; mechanism in the [framework](https://github.com/AIE3905-Wuwa/vault-wiki) (.meta/docs/packages.md).
